# Student Management System (Python)

A console-based Student Management System built using Python.

## Features

* Add Student
* View Students
* Search Student
* Find Topper
* Calculate Average Marks
* Display Top 3 Students
* Save Data to File
* Auto Load Data on Startup

## Concepts Used

* Variables
* Lists
* Functions
* Loops
* Conditional Statements
* Sorting
* File Handling
* Exception Handling

## How to Run

```bash
python student_management.py
```

## Project Goal

This project helps manage student records and analyze academic performance while strengthening Python fundamentals.
